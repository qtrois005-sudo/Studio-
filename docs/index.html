GEO VOICE État du projet

Votre position vous parle.

GEO VOICE écoute le GPS de votre téléphone et vous informe à voix haute pendant vos déplacements — sans jamais transformer une estimation en certitude.

Télécharger l'APK Android · version de test (debug) · environ 10 Mo

Comment ça marche

Trois étapes, du lancement de l'application à la première annonce.

  1. 1

    Autorisez la localisation

    L'application explique exactement ce qu'elle utilise, avant de le demander.
  2. 2

    Démarrez le suivi

    Une notification reste visible tant que GEO VOICE est actif.
  3. 3

    Marchez, roulez, écoutez

    Distance parcourue et changements de lieu sont annoncés au bon moment.

Elle ne devine jamais

Beaucoup d'applications de localisation affirment plus qu'elles ne savent. GEO VOICE évalue un niveau de confiance avant chaque annonce.

  • Confiance haute Vous êtes actuellement à Abobo.
  • Confiance moyenne Vous êtes probablement dans cette zone.
  • Confiance faible Aucune annonce — le silence plutôt qu'une supposition.

État du projet

GEO VOICE est en développement actif. Cette version est une build de test (debug), pas encore publiée sur le Play Store — Android vous demandera d'autoriser l'installation depuis une source inconnue après le téléchargement.

Le code source est public sur GitHub.
